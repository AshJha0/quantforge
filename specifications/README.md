# Domain specification index

Each domain specification is a living contract. Do not begin implementation of a non-trivial model until the equations, conventions, inputs, outputs, failure modes, validation cases and acceptance criteria are reviewed.

Domains:
1. `01-core` — financial mathematics and shared foundations
2. `02-curves` — curves and term structures
3. `03-calibration` — calibration and parameter estimation
4. `04-pricing` — pricing and valuation
5. `05-volatility` — volatility and quantitative models
6. `06-risk` — risk analytics
7. `07-portfolio` — portfolio analytics
8. `08-hedging` — hedging and optimisation
9. `09-microstructure` — market microstructure and liquidity
10. `10-execution` — execution analytics
11. `11-research` — systematic research and backtesting
12. `12-platform` — production infrastructure and governance
