| J-W2-2 | Mean-variance problem | Maximise `mu'w - (gamma/2) w' Sigma w` subject to `sum w = 1` and `lower <= w <= upper`. Defaults `lower = 0`, `upper = 1` (long-only, fully invested). `Sigma` must be symmetric (J-W2-3) and positive definite, so the optimum is unique and any correct solver gives the same weights; the method is free (active set recommended) |
| J-W2-3 | Symmetry and definiteness | A matrix is symmetric when `|S_ij - S_ji| <= 1e-12 max|S|`; otherwise `E_DOMAIN`. Positive definite means a Cholesky factorisation succeeds with every pivot `> 0`; a failure is `E_DOMAIN`. Builds use the upper triangle after the symmetry check |
| J-W2-4 | `at_bound` and strict complementarity | `at_bound_i` is `-1` when `w_i` equals `lower_i`, `+1` when it equals `upper_i`, else `0`; a build sets a bound weight to the bound exactly. Goldens keep strict complementarity: every free weight at least `1e-6` from its bounds and every bound multiplier at least `1e-6` in size, so `at_bound` is the same for any correct solver. Infeasible bounds (`sum lower > 1`, `sum upper < 1`, or `lower_i > upper_i`) are `E_DOMAIN` |
| J-W2-5 | Risk parity | Long-only, fully invested weights whose risk contributions `w_i (Sigma w)_i` are proportional to the budgets `b_i > 0`. Budgets must sum to 1 within `1e-12` (else `E_DOMAIN`); the solution uses `b_i / sum b`. For positive definite `Sigma` the solution exists and is unique ([Spinu13], [Roncalli13]). Tolerance class `root_finding` |
| J-W2-6 | Euler contributions | Volatility `sigma = sqrt(w' Sigma w)`; marginal `(Sigma w)/sigma`; contribution `w_i (Sigma w)_i / sigma`; share `contribution/sigma`. Weights may be negative; `Sigma` must be symmetric but need not be definite; `w' Sigma w <= 0` is `E_DOMAIN`. Contributions sum to `sigma` (J-8 property, 1e-10) |
| J-W2-7 | Ledoit-Wolf conventions | The scaled-identity target of [LW04]: returns demeaned by column, sample covariance with divisor `T` (not `T - 1`), `m = tr S / N`, `d^2 = ||S - m I||^2 / N`, `bbar^2 = (1/T^2) sum_t ||x_t x_t' - S||^2 / N`, `b^2 = min(bbar^2, d^2)`, `delta = b^2/d^2`, and `delta = 0` when `b^2 = 0`. These are the conventions of scikit-learn's `ledoit_wolf` with `assume_centered = False` (J-6 oracle-only check). `T >= 2` |
| J-W2-8 | Black-Litterman form | Prior mean `pi` supplied by the caller (for example `delta Sigma w_mkt`, computed outside). Posterior mean `pi + tau Sigma P' (P tau Sigma P' + Omega)^-1 (q - P pi)`; `posterior_covariance` is the covariance of the mean estimate `tau Sigma - tau Sigma P' (P tau Sigma P' + Omega)^-1 P tau Sigma`; `predictive_covariance = Sigma + posterior_covariance` ([HL99]). `Omega` symmetric positive definite (no infinite-variance views); at least one view |
| J-W2-9 | Baum-Welch tolerance | Fitted parameters are compared with an absolute `1e-12` plus relative `1e-9` limit (plan 12.10 A4) through each case's `tolerance_limit`; `log_likelihood` with class `likelihood_sum`; `iterations` and `converged` exact |
| J-W2-10 | ES backtest sign convention | Losses are positive numbers (a loss of 3 is `3`); `var` and `es` are positive loss levels. Exception when `L_t > VaR_t` (strict). `Z2 = 1 - sum_t L_t 1{L_t > VaR_t} / (T alpha ES_t)`: 0 under a correct model, negative when ES is understated. The paper's critical values are not outputs (they depend on the tail model); a study reads them from its own simulation (gap item G13) |
| J-W2-11 | Baum-Welch iteration | One iteration is one M-step followed by the E-step at the new parameters. `log_likelihood` and the output parameters are the pair from the last E-step. The iteration stops after the first iteration whose gain (new minus previous log-likelihood) is `< tolerance` (`converged = true`), or after `max_iterations` iterations (`converged = false`). A negative gain from rounding counts as converged |
| J-W2-12 | Stop-rule margin in goldens | Every stop test a golden evaluates is decided by at least `1e-11` in absolute log-likelihood, so every build stops at the same iteration; the generator picks each case's `tolerance` between two consecutive gains to meet this (an input, not a tuned answer). Builds need no special handling |
| J-W2-13 | Baum-Welch degeneracies | An E-step scale `c_t = 0` (the observations have zero density under every state in binary64), a zero denominator in the transition update, or a new variance `<= 0` is `E_DOMAIN`. No variance floor and no state relabelling: the start values fix the labels |
| J-W2-14 | `E_LIMIT` sizes | Assets 500 and views 500 (optimisation, estimation, Euler); rows 1,000,000 and cells 10,000,000 (Ledoit-Wolf returns, ES backtest series, Baum-Welch observations); states 16; `max_iterations` 10,000; Baum-Welch `T K` at most 10,000,000. These page limits replace the CLI's general array limit, as J-20 |
