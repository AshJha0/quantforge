# Stage K rulings for K-3 (adapters and simulated feeds): PROPOSED

Status: PROPOSED by lane `k-v1-k3` on 2026-11-20. Not normative until the stage K coordinator confirms each row. Reviewer: none: self-assessment; no second review (owner decision 2026-11-18). Spec: `specifications/12-platform/adapters.md` (version 0.2.0-proposed). These rows replace the K-3 rows KR-180 to KR-189 of the unconfirmed draft on branch `k-w3-spec` (`specifications/stage-k-rulings-w3.md`); the new block starts at KR-270, checked free with `git grep` on every remote branch on 2026-11-20 (KR-260 was the highest number found in the 260 to 299 range).

Coordinator decisions already taken under the owner's delegation (2026-11-20) and written into these rows: Grafana dropped (AGPL); containers on GitHub Actions only; free images with licences recorded; FIX, ITCH, OUCH, FAST and multicast formats simulated from public knowledge to this project's own simplified layouts, labelled "simulated; not a certified implementation; not connected to any venue"; no exchange specification document downloaded or opened; no London Stock Exchange or LSEG material.

| ID | Topic | Ruling |
|---|---|---|
| KR-270 | Round-trip records | 10,000 generated records `{seq, kind, body}` from `next_u64(20261109, seq, 4)` by the rules of adapters.md §1.1; decimals as strings, one exact binary64 `value`; file and its SHA-256 committed before any adapter run. No recorded market data (was KR-180) |
| KR-271 | One content hash | SHA-256 over the `01-core/snapshot-hash.md` canonical form of each record, sorted by `seq`, each followed by LF; count rule (`COUNT`) before the hash; feed bytes hashed in sequence order (was KR-181) |
| KR-272 | Images | Free images only, licence read on the project's own page with URL and date; every compose `image:` pinned as `name:tag@sha256:<index digest>` and listed in `platform/compose/images.lock`; the driver refuses anything else (`UNPINNED`) (was KR-182) |
| KR-273 | Grafana and Aeron | Grafana dropped (AGPLv3; recorded scope change SC-1, known issue KI-K3-GRAFANA); Prometheus alone meets the metrics row. No official Aeron image exists, so Aeron runs as our Java programs on the `eclipse-temurin` image with the Apache 2.0 Aeron jar from Maven Central; this is the substitute, stated as such (was KR-183) |
| KR-274 | Simulated formats | Five formats defined by adapters.md §3 itself (QF-FIX-S, QF-ITCH-S, QF-OUCH-S, QF-FAST-S, QF-MOLD-S), from recalled public knowledge of the protocol families; no vendor or standards document is a source; no conformance claimed. FIX BeginString is `QFSIM.1` so no message can be mistaken for real FIX (was KR-184) |
| KR-275 | Label and values | Every fixture sidecar, codec module docstring and adapter result carries "simulated; not a certified implementation; not connected to any venue". Symbol `QFSIM`; all values invented (was KR-185) |
| KR-276 | Canonical encodings | Every format's encoding is canonical: `encode(decode(b)) = b` for every `b` that decodes. Non-minimal stop-bit integers and presence maps are rejected (`E_OVERLONG`) rather than accepted, so byte equality is a valid test |
| KR-277 | FAST-style dictionary | One template; the dictionary is reset at the start of every packet; absent copy or increment field with an empty dictionary entry is `E_FIELD` |
| KR-278 | Multicast | Met by QF-MOLD-S packets over UDP multicast inside the Compose network, one sender, two listeners, ITCH-style payloads, gap detection by sequence number; a planted dropped packet must be reported as one gap (was KR-187) |
| KR-279 | Decoder errors | Decoders raise only `FeedError` with one of eight codes, checked in the order of adapters.md §3; random-byte fuzzing must never produce another exception |
| KR-280 | Where adapters live | `platform/` (separate Python distribution `quantforge-adapters`, separate Maven project for Aeron, compose files); they may depend on the libraries, never the reverse (was KR-189) |
| KR-281 | Libraries without services | `tools/check_adapter_deps.py` (static, four languages, with a planted-fault self-test) in repo gates on every pull request; CI job `libraries-without-services` builds the Python and Java libraries with no adapter package; Rust and C++ are checked statically only. The draft's "red on two planted branches" is replaced by the self-test plants, which run on every pull request (was KR-186) |
| KR-282 | Codec languages | Python is the K-3 codec deliverable (as the draft's KR-188); Java, Rust and C++ codecs are not built in v1.0.0 and are listed in known issues; the shared fixtures and `malformed.json` are the test for any later port |
| KR-283 | Service hash without the library | The REST and gRPC services run on Python 3.13 and compute the snapshot hash with the adapter package's canonical-form function, checked byte-identical to `quantforge_core.snapshot.canonical` over all 10,000 records in the local tests; the library requires Python 3.15, and `grpcio` wheels for 3.15 were not established |
