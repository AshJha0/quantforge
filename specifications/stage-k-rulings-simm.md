# Stage K rulings, SIMM structure on placeholder weights (K-8h): PROPOSED

Written 2026-11-19 by the K-8h spec lane (branch `k-simm-spec`; reading and writing only). Status: **PROPOSED** until the coordinator confirms. Numbering starts at KR-130 so it cannot collide with the other stage K lanes (KR-1 to KR-111 used so far). Append-only. Spec: `specifications/06-risk/simm-placeholder.md`; table: `specifications/tables/stage_k/simm-placeholder.json`.

Why these rulings exist: the SIMM methodology was not read in this lane (isda.org refused the automated fetch; spec section Sources), so every structural choice below is either recalled or ours. Each ruling says which way we go so that four language builds and a blind deriver make the same choice; none claims to state ISDA's text.

| # | Point | Ruling |
|---|---|---|
| KR-130 | Label and parameter rule | Owner decision K-QE: the operation runs on placeholder weights only. Every output carries `label` "placeholder weights; SIMM aggregation structure only; not ISDA SIMM initial margin"; every doc, table, golden and packet that shows one of its numbers says "placeholder weights". No ISDA parameter value (risk weight, correlation, threshold, scaling constant, quantile) may appear in the repository. The Open Source Risk Engine's SIMM calibration files are not opened or used (`program/STAGE_K_ORE_SURVEY.md` section 5). Never contact ISDA or a vendor. |
| KR-131 | Scope | Risk classes IR, FX, EQ; product classes RatesFX, Credit, Equity, Commodity as grouping labels. IR and EQ: delta, vega, curvature; FX: delta only. EQ buckets 1, 2, 3 and RESIDUAL; one IR bucket per currency, one curve per currency; one FX bucket. Left out: credit (qualifying and non-qualifying, so base correlation), commodity, FX vega and curvature, IR sub-curves, inflation, cross-currency basis, currency volatility groups, historical volatility ratio, curvature scale factors other than SF, add-on and product-class multipliers, regulatory schedules and posting directions, FX conversion. A smaller complete scope was chosen over a broad one that could not be specified without reading the methodology. |
| KR-132 | Risk factors and netting | A risk factor is identified within one product class by (risk type, qualifier, and for IR also `label1`); EQ vega is one factor per issuer over all expiries; delta and vega never net; nothing nets across product classes. Records of one factor are summed (signed) before any weight or concentration. `trade_id` is carried and never used. |
| KR-133 | Clipped bucket sum | `S_b = max(-K_b, min(sum of WS_k in b, K_b))` for delta and vega, and the same on CVR for curvature. There is no unclipped first attempt and no alternative correlation scenario. |
| KR-134 | Radicand floors | Every square root in the algebra is taken of `max(0, x)`. This is a ruling, not a recalled SIMM statement (the same choice as KR-62 for SA-CVA). With the placeholder table no golden reaches a negative radicand, and no output flag is defined for it. |
| KR-135 | Curvature theta at 0/0 | `theta = min(sum CVR / sum abs(CVR), 0)`; when every CVR of the part (non-residual or residual) is 0, `theta = 0` and `lambda = z^2 - 1`. |
| KR-136 | Empty and absent levels | No records: `total = 0`, `product_classes` empty; this is valid, not an error. A product class, risk class or margin kind with no records is absent from the output and contributes 0. A curvature part with no factors contributes 0 and its `theta`, `lambda`, `sum_cvr` (or `residual` object) are absent. An EQ kind with only residual factors has no `buckets` entries and `M = 0`. |
| KR-137 | Concentration groups | IR: the currency (one factor set per bucket, so `f_kl = 1` inside an IR bucket and `CR_b` is the common value used in `g_bc`); FX: the currency; EQ: the issuer. Delta uses the delta threshold, vega the vega threshold. Curvature has no concentration factor. The group sum is signed before the absolute value. |
| KR-138 | Correlations | IR within a bucket: the tenor matrix on the two factors' `label1` (vega: on the expiries). FX: one number. EQ: one number per bucket, RESIDUAL its own. Across IR buckets `gamma x g_bc` with `g_bc = min(CR_b, CR_c) / max(CR_b, CR_c)`; across EQ buckets `gamma` alone; RESIDUAL takes part in no cross-bucket sum and is added outside the root. Curvature uses the vega correlations squared and no `f_kl` or `g_bc`. Across risk classes in one product class `psi`; across product classes a plain sum. |
| KR-139 | Numbers and errors | As KR-67: binary64 JSON numbers, the F-2 finite rule, goldens to 1e-12 relative (1e-15 absolute at 0), error order `E_SCHEMA`, `E_LIMIT` (more than 100,000 records), the finite rule (`E_DOMAIN`), structural `E_INPUT`, `E_DOMAIN`; a golden with two errors at once (lesson HR-66). |
| KR-140 | Tenor days and SF | `1W` 7, `1Y` 365, `5Y` 1825, `10Y` 3650 days, from the placeholder table. `SF(t) = sf_scale x min(1, sf_days / t)`; both constants are placeholders (0.25 and 20), not methodology values. |
| KR-141 | Outside-check class | A value case counts as outside-checked only as class B of KR-68 (blind re-derivation under DR-H2). No class P (no number printed in a read source is computed on placeholder weights) and no class L (no independent library is usable without licensed parameters). A B match shows the spec is unambiguous and the arithmetic consistent on placeholder weights; it does not show agreement with ISDA SIMM (`program/STAGE_K_BLIND_SIMM.md`, gate note). |
