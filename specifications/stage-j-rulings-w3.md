# Stage J rulings, wave 3 (spec lane)

Normative for stage J (v0.9) wave 3: the G18 scenario stress engine and historical shock library, the leave-one-out and held-out-strike interpolation backtests, and the A3 drift detectors. A separate file from `stage-j-rulings-w1.md` and `-w2.md` so branches merge without conflict. Wave 1 and wave 2 rulings still hold where they are general (check order, limits before rules, F-2 finite inputs).

Owner decision 2026-11-15: wave 3 is Option C, all in v0.9.0. This file and the three spec pages were committed **before** any Treasury file was downloaded for wave 3, any backtest was run or any drift path was drawn (pass rules first, plan 14.10).

| # | Point | Ruling |
|---|---|---|

No new error code |
| J-W3-2 | Units | Yields are in percent (Treasury's own unit, `4.25` = 4.25 %); shocks and shifts in basis points; tenors in years (1M = 1/12, 3M = 0.25, 6M = 0.5). `shift_bp = 100 (end - start)` computed in binary64 from the percent values as given |
| J-W3-3 | Date lookup | `historical_shock` needs `dates` strictly increasing (else `E_DATE_ORDER`). A `start_date` or `end_date` not in `dates` is `E_DOMAIN` (no roll to a neighbouring day inside the op). `end_date` must be after `start_date` (else `E_DATE_ORDER`). The library (J-W3-6) states its dates exactly; if a named date had had no Treasury row the library would have used the previous row and said so |
| J-W3-4 | Replay interpolation | `replay` maps a shock given on `shock_tenors` onto `base_tenors` linearly in tenor, flat beyond the first and last shock tenor. `scale` (default 1) multiplies the shock. P&L is first order: `pnl = - sum_i dv01_i applied_bp_i`, with `dv01_i` the value gained per 1 bp fall in yield at tenor `i` (positive for a long bond); `dv01` is optional and `pnl` is output only when it is given |
| J-W3-5 | Missing values | Treasury cells may be blank (a tenor not yet issued, a holiday column). Op inputs carry no blanks: the library build drops tenors with a blank on either named date and lists them |
| J-W3-6 | Shock library | `datasets/scenarios/us_treasury_shocks.json`, built by `datasets/scenarios/build_shock_library.py` from Treasury daily par yield CSVs stored under `datasets/scenarios/raw/` with URL, UTC retrieval time and SHA-256 in `datasets/scenarios/raw/provenance.csv`. Named windows, fixed here before download: `gfc_2008` 2008-09-12 to 2008-12-31; `taper_2013` 2013-05-01 to 2013-09-05; `covid_2020` 2020-02-19 to 2020-03-09; `hikes_2022` 2021-12-31 to 2022-10-21. Tenor set 1M, 3M, 6M, 1Y, 2Y, 3Y, 5Y, 7Y, 10Y, 20Y, 30Y |
| J-W3-7 | J-8 acceptance, scenarios | Passes only if both hold: (1) every library shift equals `100 (end - start)` of the stored Treasury rows to `1e-9` bp, recomputed by the conformance golden `scen_j` from the raw rows; (2) every start and end yield equals the Federal Reserve H.15 constant-maturity value for the same date and tenor (FRED series DGS1MO, DGS3MO, DGS6MO, DGS1, DGS2, DGS3, DGS5, DGS7, DGS10, DGS20, DGS30, public CSV, no account) to within 0.005 percentage points (half the published rounding unit). H.15 is a separate publication of the same Treasury curve, so (2) is an outside check of the stored data, not of a model. Scenario replay: the replay of each library shock onto its own start curve gives the end curve to `1e-12` |
| J-W3-8 | Leave-one-out | For each interior knot `i = 1 .. n-2`, the interpolant is built on the other `n-1` knots with `core.interp.evaluate` conventions (`linear`, `log_linear`, `cubic_natural`, `monotone_pchip`) and evaluated at `x_i`; `error_i = fitted - y_i`. End knots are not left out (that would be extrapolation). `n - 1` must reach the method's minimum knot count and `n >= 3`, else `E_INPUT` |
| J-W3-9 | Held-out strikes | `surface_holdout` interpolates total variance `w = sigma^2 T` in log-moneyness `k` per expiry on the kept strikes, and converts back `sigma = sqrt(w / T)`; error in vol units `sigma_fit - sigma_true`. Held-out indices must be interior (not the first or last strike), distinct and sorted, else `E_INPUT`. Interpolated `w <= 0` is `E_DOMAIN` |
| J-W3-10 | CUSUM | Standardised `z_t = (x_t - mu0) / sigma`; `S+_t = max(0, S+_{t-1} + z_t - k)`, `S-_t = max(0, S-_{t-1} - z_t - k)`, both starting at 0. Alarm at `t` when `S+_t > h` (direction `+1`) or `S-_t > h` (`-1`; if both, `+1`). After an alarm both sums restart at 0 (`reset`, default true); with `reset = false` only the first alarm is reported |
| J-W3-11 | Page-Hinkley | From the last restart `r`: `xbar_s` the mean of `x_r .. x_s`; up-test `m_t = sum_{s=r..t} (x_s - xbar_s - delta)` (each term uses the running mean at its own step; with `xbar_t` in every term the sum would be `-(t - r + 1) delta` identically, a slip corrected on 2026-11-15 before any code ran), `M_t = min_{s<=t} m_s`, alarm when `m_t - M_t > lambda`; down-test symmetric with `-x`. `direction` input `up`, `down` or `both` (default). Restart after an alarm as J-W3-10. The running-mean form follows the usual data-stream statement ([GAMA14]) |
| J-W3-12 | PSI bins | `B` bins from the reference sample: edges `e_j = r_(ceil(j n / B))` (order statistics, 1-based, type 1 inverse empirical CDF), `j = 1 .. B-1`; bins `(-inf, e_1], (e_1, e_2], .., (e_{B-1}, inf)`. Proportions floored at `1e-4` (no renormalisation); `PSI = sum (a_j - r_j) ln(a_j / r_j)`. `alarm` when `PSI > threshold` (default 0.25). Tied edges give empty bins, which the floor handles |
| J-W3-13 | KS statistic and p-value | `D = max |F_n - G_m|` over the pooled sample, ties handled by evaluating both empirical CDFs after all equal values. Two-sided p-value `P(D' >= D)` under the continuous null: exact lattice-path count in integers (`D n m` is an integer), so the value is exact to binary64 rounding of one final division. With ties the continuous-null p-value is still reported (conservative statement in the spec). `reject` when `p <= level` |
| J-W3-14 | `E_LIMIT` sizes | Scenario: dates 100,000, tenors 100. Backtests: knots 10,000; strikes 1,000; expiries 1,000. Drift: series 10,000,000; PSI samples 1,000,000 each, bins 1,000; KS `n m <= 4,000,000`. Page limits as J-20 |
| J-W3-15 | Outside checks planned | Interp LOO and surface holdout: scipy `CubicSpline(bc_type="natural")` and `PchipInterpolator` (`library-object`), numpy `interp` for linear. KS: scipy `ks_2samp(method="exact")` (`library-object`). PSI, CUSUM, Page-Hinkley: no free library with these exact conventions; hand cases plus an independent exact-arithmetic oracle (`reimplementation`, does not count). Scenarios: FRED H.15 (J-W3-7) for the data. Shares are reported after generation, with and without added cases (14.10 rule 3) |
| J-W3-16 | Backtest pass rules | Fixed in `11-research/interp-backtest.md` section "Pass rules" before any run; results in `research/interp_backtest/RESULTS.md`; a fail is published with the same prominence |
