# W33: Cross-language parity campaign

## Objective
Run all supported fixtures across Python, C++, Java and Rust implementations.

## Work items
- [ ] Review the relevant domain specification and ADRs.
- [ ] Refine mathematical assumptions, units, conventions and failure behaviour.
- [ ] Add deterministic test fixtures before or alongside implementation.

## Acceptance criteria
- [ ] Conformance report includes versions, skipped tests, max errors and independent expected-value provenance.

- [ ] No unsupported production-readiness claim is made.

## Demo

## Risks / open questions
