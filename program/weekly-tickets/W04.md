## Key formulas
Newton: `x' = x - f(x)/f'(x)`, with a bracket as a safeguard. Central differences: `(f(x+h) - f(x-h))/(2h)`.

Gauss-Legendre weights: `w_i = 2/((1 - t_i^2) P_n'(t_i)^2)`.

Monotone convex: `f(s) = fd_i + g(x)`, with `g` integrating to 0 on each interval, so inputs reprice.

COS: `exp(-rT) sum' Re[phi(u_k) exp(i u_k (x - a))] V_k`, pricing the put, then parity.

Crank-Nicolson with Rannacher start-up: `(I - theta s L) V_new = (I + (1 - theta) s L) V_old`.

The specs hold the full definitions and edge cases.
