# W03: Market-data types and contracts

Stage A. Bad data is labelled, never repaired or dropped, and nothing is overwritten.

## Specification
`01-core/data-checks.md`, `snapshot-hash.md`, `asof-store.md`, `datasets/schemas/`. Paths are under `specifications/` unless stated.

## Key formulas
Robust outlier score: `|mid - median| / (1.4826 MAD)`.

Snapshot id: `sha256` of the canonical form, each number written as `#` and its 16 hex binary64 digits.

Chain: `h_i = sha256(h_{i-1} + canonical(record_i))`.

The specs hold the full definitions and edge cases.
