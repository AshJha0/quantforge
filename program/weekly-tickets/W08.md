# W08: Rates bootstrap

Stage B. A curve is whatever makes every input quote reprice.

## Specification
`02-curves/ois-curves.md`, `02-curves/schedules.md`. Paths are under `specifications/`.

## Key formulas
Solve `K_j(curve) = quote_j` for all `j`, in order (`SEQUENTIAL`) or together (`GLOBAL`), below 1e-13.

The specs hold the full definitions and edge cases.
