# W13: Black pricing and implied volatility

## Objective
Implement Black-Scholes/Black-76 pricing and implied-volatility inversion.

## Work items
- [ ] Review the relevant domain specification and ADRs.
- [ ] Refine mathematical assumptions, units, conventions and failure behaviour.
- [ ] Add deterministic test fixtures before or alongside implementation.
- [ ] Implement independently in Java, C++, Python and Rust from the specification.
- [ ] Run unit, property, boundary and conformance tests.
- [ ] Record numerical diagnostics and benchmark evidence where relevant.
- [ ] Update documentation, examples and known limitations.

## Acceptance criteria
- [ ] No-arbitrage bounds, expiry and zero-vol cases tested; inversion recovers known vol.
- [ ] PR links the issue and records tested toolchain versions.
- [ ] No unsupported production-readiness claim is made.

## Demo
Show one reproducible end-to-end example and its validation evidence.

## Risks / open questions
Record unresolved conventions, data dependencies, algorithm choices and performance constraints in the issue before implementation.
