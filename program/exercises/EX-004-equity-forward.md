# Exercise: Equity forward

## Task
Implement a simple carry-based equity forward with explicit dividend and financing assumptions.

## Questions
1. How does a cash dividend affect forward value?
1. What changes for discrete dividends?
1. How would you test zero time to expiry?

## Submission requirements
- Code and tests in the relevant language directory.
- A short mathematical explanation.
- Normal, boundary and invalid cases.
- Expected output and independent verification method.
- Complexity/performance note where relevant.
