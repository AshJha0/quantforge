# Exercise: FX forward

## Task
Implement an FX forward using explicit base/quote currency orientation and discount curves.

## Questions
1. How can quote orientation reverse the formula?
1. What happens if rates are equal?
1. How should points be represented?

## Submission requirements
- Code and tests in the relevant language directory.
- A short mathematical explanation.
- Normal, boundary and invalid cases.
- Expected output and independent verification method.
- Complexity/performance note where relevant.
