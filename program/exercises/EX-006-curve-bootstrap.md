# Exercise: Curve bootstrap

## Task
Build a simple curve from coherent synthetic instruments generated from a known curve.

## Questions
1. Why should synthetic quotes be generated from known parameters?
1. How do you measure repricing residuals?
1. What makes a bootstrap underdetermined?

## Submission requirements
- Code and tests in the relevant language directory.
- A short mathematical explanation.
- Normal, boundary and invalid cases.
- Expected output and independent verification method.
- Complexity/performance note where relevant.
