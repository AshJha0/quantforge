# Exercises

Exercises are language-neutral. Solve each independently in Java 25, C++26, Python and Rust, in any order. Do not copy an algorithm without understanding its invariants, numerical properties and failure cases.

EX-001 to EX-003 have data in `data/` and solutions in `solutions/`, with values from `oracle/python/gen_exercises.py`. EX-004 to EX-012 are questions only for now; their data and solutions arrive with their stages.
