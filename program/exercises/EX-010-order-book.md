# Exercise: Order-book reconstruction

## Task
Replay snapshots and incremental events into a deterministic order book; handle sequence gaps.

## Questions
1. Why must sequence gaps be detected?
1. What is the difference between L2 and L3 data?
1. How should out-of-order events be handled?

## Submission requirements
- Code and tests in the relevant language directory.
- A short mathematical explanation.
- Normal, boundary and invalid cases.
- Expected output and independent verification method.
- Complexity/performance note where relevant.
