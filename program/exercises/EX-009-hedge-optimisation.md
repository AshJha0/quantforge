# Exercise: Hedge optimisation

## Task
Solve a small constrained least-squares hedge problem with transaction-cost penalty.

## Questions
1. How do you detect infeasible constraints?
1. How does regularisation change the solution?
1. How do you report residual risk?

## Submission requirements
- Code and tests in the relevant language directory.
- A short mathematical explanation.
- Normal, boundary and invalid cases.
- Expected output and independent verification method.
- Complexity/performance note where relevant.
