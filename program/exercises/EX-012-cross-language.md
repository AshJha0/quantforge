# Exercise: Cross-language conformance

## Task
Implement one shared fixture in Python, C++, Java and Rust and generate a comparison report.

## Questions
1. Why is agreement not proof of correctness?
1. How should tolerances be chosen?
1. What metadata makes a report reproducible?

## Submission requirements
- Code and tests in the relevant language directory.
- A short mathematical explanation.
- Normal, boundary and invalid cases.
- Expected output and independent verification method.
- Complexity/performance note where relevant.
