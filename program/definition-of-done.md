# Definition of done

A feature is complete only when all applicable items are satisfied.

## Mathematical
- [ ] Equations, assumptions, conventions and units documented.
- [ ] Independent expected-value evidence supplied.
- [ ] Numerical conditioning and failure cases understood.

## Engineering
- [ ] Public interfaces and error semantics documented.
- [ ] No accidental cross-language runtime dependency.
- [ ] Code formatted and static analysis clean.
- [ ] Unit, property, regression and boundary tests pass.

## Data and reproducibility
- [ ] Input schema and provenance explicit.
- [ ] Deterministic fixture or replay instructions supplied.
- [ ] Model/configuration version included in result metadata.

## Conformance and performance
- [ ] Cross-language tests pass where applicable.
- [ ] Tolerances justified and reported.
- [ ] Benchmark evidence added when performance is relevant.

## Delivery
- [ ] Documentation and examples updated.
- [ ] Limitations and unsupported cases listed.
- [ ] Review approved and linked issue closed.
