# Blind lane notes (interpretations)
Shapes were not fully specified; chosen as follows. Decimals are JSON strings (exact); counts and ticks are integers. Every ok output carries "label" (HR-94): auction/equities "simulated venue; not a real exchange"; FX adds "; no real FX data"; rates adds "; no real rates data".
- eqc round_price: output price quantised to the applicable tick's decimals ("1.0000", "25.00"); plus "tick". 0.99995 sell rounds up to 1.0000 (valid on both grids).
- eqc_h-0007: cap = 0.003 for price >= 1 (0.3 % of price below); fee 0.0031 > cap gives E_DOMAIN.
- auc: order ids taken from the seq labels s1..s6 in auc_h-0001/2; other cases use ids b1/b2/a1/a2 by order of listing, seq = listing order. Fills list buys first, then sells, each in allocation order, each {id,side,qty,price}. imbalance = B-S at the chosen price (before allocation). auc_h-0002 = same output as 0001 (fills and residual are in both). Residual = resting limit orders with remaining qty; "cancelled" lists unfilled MARKET ids.
- auc_h-0007 (market only, no candidate) and 0008 (one side empty): price null, volume 0, imbalance reported as 0 (spec silent); in 0007 both market orders are cancelled, in 0008 both buys rest. ref_price not given, irrelevant.
- auc_h-0003/4/5: all I=0 so ref decides; 10.005 ties 10.00/10.01, higher p wins (HR-96).
- fxv stream: single-point mid_path at time 0; bid rounded down, ask up to the tick. Request: price is the ask for BUY, bid for SELL; qty irrelevant to outcome. fxv_h-0007 non-symmetric: move -4 is favourable to dealer for a client BUY, so FILL.
- fxc pip_value = notional x pip in the quote currency (fields pip, pip_value, currency). Spot date: T+2 counted over days good in both currencies, then rolled to a USD good day; USDCAD T+1. USD holiday 2026-11-26 gives 2026-11-27. USDEUR: E_INPUT.
- rtc parse: value (decimal string) and exact fraction. Format: "101-09+" for 101.296875 at 64; 101.3 not on the 1/128 grid, E_DOMAIN. Prices rounded to 12 dp half-even (bond 99.036287923855; coupon-date 2y at par 100.000000000000; bill 98.736111111111 = 100(1-0.05*91/360)). Tick value printed with 6 dp via Decimal division ("15.625000").
- fut_h-0004/5: the buy at 110-16 and sell at 110-17+ do not cross in a book (bid below ask), so read as one participant's round trip, pnl = (7075-7072) x 3 x 15.625 = 140.625; fee 1.00 per contract per side = 6 contracts = 6.00, pnl 134.625. fut_h-0006: entry 3840 ticks, settle 3839, variation margin = -1 tick x 1 x 31.25 = -31.25 (previous mark = fill price assumed). fut_h-0003: 110-162 is 7072.5 ticks, E_DOMAIN.
