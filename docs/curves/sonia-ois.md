## What it is

SONIA is the sterling overnight rate. An overnight indexed swap (OIS) pays a fixed rate against that rate compounded daily, so a set of OIS quotes says what sterling paid later is worth today. The curve is whatever set of discount factors makes every quoted swap worth zero.

Formally: Par rate `K = F / A`, with annuity `A = sum alpha_i D(p_i)` and floating leg `F = sum (D(s_i)/D(e_i) - 1) D(p_i)`. The solve finds `D` so that `K_j(curve) = quote_j` for every quote `j`. Here spot lag and payment lag are 0, the fixed leg is annual, and the day count is `ACT_365F`. Spec: `specifications/02-curves/ois-curves.md`.

## How to generate it

Input file: [`examples/ois_bootstrap.json`](../../examples/ois_bootstrap.json). Build a CLI as in the [Cookbook](../../COOKBOOK.md), then from the repository root:

```bash
rust/target/release/quantforge run < examples/ois_bootstrap.json
```

The charts then send the pillars to `rates.curve.discount` and `rates.curve.forward` on a grid of quarterly dates plus every pillar. To rebuild every page, with all four CLIs built:

```bash
python tools/build_gallery.py
```

Raw numbers: [`docs/curves/data/sonia-ois.json`](data/sonia-ois.json).

## Oracle evidence and limits

Pillars are compared with QuantLib `OISRateHelper` curves, and swap PVs with QuantLib and with Strata's swap pricer on the same curve. Strata's calibrator has not been run, so no curve here was built by it. The target is 1e-9 on pillars; the oracle's measured gap to QuantLib is within 2e-11 (`specifications/02-curves/stage-b-targets.md`).

Golden cases for `rates.ois.bootstrap` with an `ok` result and convention SONIA: 18, counted from `verified_by` in `datasets/golden/stage_b/`. All four builds passed them locally, which is self-assessment.

| Suite | Verified by | Cases |
|---|---|---|
| ois | independent-replay | 1 |
| ois | independent-replay, quantlib-1.44 | 9 |
| ois_deep | independent-replay, quantlib-1.44 | 8 |

Limits:

- Exact repricing shows the solve works. It would do so on any coherent quotes, and says nothing about fit to a market.
- Log-linear interpolation of discount factors gives flat forwards between pillars, so the forward chart is a staircase by construction.
- No meeting-date steps, turn-of-year effects, or lookback, lockout and observation shift: those are stage D.
