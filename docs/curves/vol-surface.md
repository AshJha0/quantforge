# Implied volatility surface from SVI slices

<p class="note">Status: Implemented, not Validated. Validation is self-assessment until the human review at the end of the project. Data: synthetic. These are constructed inputs, not market data, and nothing is traded.</p>

Generated on 2026-11-08 from commit `597abf2`, by Java 0.4.0 (JDK 25.0.5+8-LTS), C++ 0.4.2 (GCC 16.2.0), Python 0.4.0 (CPython 3.15.2), Rust 0.4.2 (rustc 1.99.1), on one Windows machine.

## What it is

Implied volatility across expiry and log-moneyness `k = ln(K/F)`, from three SVI slices joined in total variance, as a heat grid with smile slices at three expiries. The grid is the set of points sent to `vol.local.dupire`, which returns implied and local volatility at each point. Stage E, target v0.5.

## Inputs

Three SVI slices (0.25, 1 and 2 years) copied from golden case `lv_e-0001`, evaluated on a grid of six expiries and nine log-moneyness points. Synthetic inputs, not market data. Input: [`examples/vol_dupire_grid_e.json`](../../examples/vol_dupire_grid_e.json).

## Command

Build a CLI as in the [Cookbook](../../COOKBOOK.md), then from the repository root:

```bash
rust/target/release/quantforge run < examples/vol_dupire_grid_e.json
```

Raw numbers: [`docs/curves/data/vol-surface.json`](data/vol-surface.json).
