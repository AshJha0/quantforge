# Local volatility (Dupire)

<p class="note">Status: Implemented, not Validated. Validation is self-assessment until the human review at the end of the project. Data: synthetic. These are constructed inputs, not market data, and nothing is traded.</p>

Generated on 2026-11-08 from commit `597abf2`, by Java 0.4.0 (JDK 25.0.5+8-LTS), C++ 0.4.2 (GCC 16.2.0), Python 0.4.0 (CPython 3.15.2), Rust 0.4.2 (rustc 1.99.1), on one Windows machine.

## What it is

Dupire local volatility from the same SVI surface, as a heat grid by expiry and log-moneyness, with slices at three expiries. Local volatility is the diffusion coefficient that reprices every vanilla on the surface; its skew is steeper than the implied skew. Stage E, target v0.5.

## Inputs

The same input as the implied surface page: three SVI slices from golden case `lv_e-0001` on a six by nine grid. Synthetic inputs, not market data. Input: [`examples/vol_dupire_grid_e.json`](../../examples/vol_dupire_grid_e.json).

## Command

Build a CLI as in the [Cookbook](../../COOKBOOK.md), then from the repository root:

```bash
rust/target/release/quantforge run < examples/vol_dupire_grid_e.json
```

Raw numbers: [`docs/curves/data/local-vol.json`](data/local-vol.json).
