## What it is

SOFR is the US dollar overnight secured rate. The method is the same as for SONIA, with dollar conventions: trades start two business days out and pay two business days after each period ends. This is the minimal SOFR of stage B. Full SOFR is stage D.

Formally: As for SONIA: `K = F / A`, `F = sum (D(s_i)/D(e_i) - 1) D(p_i)`, solved so that every quote reprices. Spot lag 2, payment lag 2, annual fixed leg, `ACT_360`. The floating leg is never telescoped to `D(s_0) - D(e_n)`: with a payment lag that form is wrong, by about 1.1e-4 per unit on 10Y. Spec: `specifications/02-curves/ois-curves.md`.

## How to generate it

Input file: [`examples/ois_bootstrap_sofr.json`](../../examples/ois_bootstrap_sofr.json). Build a CLI as in the [Cookbook](../../COOKBOOK.md), then from the repository root:

```bash
rust/target/release/quantforge run < examples/ois_bootstrap_sofr.json
```

The charts then send the pillars to `rates.curve.discount` and `rates.curve.forward` on a grid of quarterly dates plus every pillar. To rebuild every page, with all four CLIs built:

```bash
python tools/build_gallery.py
```

Raw numbers: [`docs/curves/data/sofr-ois.json`](data/sofr-ois.json).

Limits:

- Each pillar sits at the swap's last payment date, so pillar dates fall after the plain tenor date.
