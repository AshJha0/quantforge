# One curve, five interpolation methods

<p class="note">Status: Implemented, not Validated. Validation is self-assessment until the human review at the end of the project. Data: synthetic. These are constructed inputs, not market data, and nothing is traded.</p>

Generated on 2026-11-10 from commit `db99d87`, by Java 0.6.0 (JDK 25.0.5+8-LTS), C++ 0.6.0 (GCC 15.2.0), Python 0.6.0 (CPython 3.15.2), Rust 0.6.0 (rustc 1.99.1), on one Windows machine.

## What it is

Between quoted dates a curve has to be filled in, and the method decides what forward rate a trader sees on any day in between. This page takes one set of 12 SOFR pillar discount factors and asks each method for the instantaneous forward rate along the curve. The discount factors at the pillars are the same in every method; only the space between them changes. Stage F, target v0.6.0 (`specifications/02-curves/curve-framework.md`, section "Stage F: pluggable interpolation").

What to look for: log-linear in `D` gives flat forwards that jump at every pillar. Monotone convex (Hagan and West) and the monotonic log cubic give continuous forwards. The tension spline sits between a cubic spline and log-linear as its tension moves from 0 to infinity. The hybrid is stepwise up to its `step_end` and smooth behind it.

## Inputs

Twelve pillars from one month to 30 years, as of 2026-11-09, the pillars of the fixed-pillar golden cases (`curve_f-0068` to `curve_f-0076`), evaluated at 203 dates. Synthetic. Input: [`examples/curve_methods_f.json`](../../examples/curve_methods_f.json); the gallery sets `interpolation` (and `tension` or `step_end`) for each method.

## Command

Build a CLI as in the [Cookbook](../../COOKBOOK.md), then from the repository root:

```bash
rust/target/release/quantforge run < examples/curve_methods_f.json
```

Raw numbers: [`docs/curves/data/interpolation-methods.json`](data/interpolation-methods.json).
