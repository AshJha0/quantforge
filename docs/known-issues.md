# Known issues: open audit findings

This page lists every open Critical or Major finding of the different-model audits of stage K round 1 (three audits, 2026-11-19, by a model that did not write the audited work; plan rule 14.10-5). It is the register that the spec "Limits" sections point to. Older known issues are in the [README](../README.md#known-issues).

**State of the code (2026-11-20).** Stage K round 1 and the round 2 fixes are released in v0.10.1 (2026-11-20, pull requests #58 and #59). The different-model audits A, B, C and the follow-up are answered; what stays open is listed below. Evidence class of every row: measured or read by the auditor, as stated in the audit; rows marked "re-measured" were also checked by the project.

Plain reading: each row says what is wrong in one sentence, with the size where one was measured. "Answered on branch X, merge pending" means a fix exists with tests but is not yet on the integration branch; the row closes when it is merged and its rulings are confirmed.
