# References

Every source the specifications cite, grouped by topic. Each entry is copied from the spec that cites it, with that spec's own status words, and links back to every spec that relies on it. Nothing here is added from memory.

How to read the marks:

- **Not opened** means the spec gives the usual citation from memory, and nobody has re-read the source for this project. Confirm it before relying on it.
- **Paywalled** marks an entry the spec calls licensed: a person with access must confirm section or equation numbers.
- DOI and arXiv links are formed from the identifiers the specs give. `tools/check_links.py` checks their HTTP status; run it by hand, as it needs the network (see `tools/README.md`).
