## Plain idea

one weighted least-squares hedge of a book's equity move and key-rate risks with forwards, options, bonds and the underlying. (Read from the inventory entry.)

## Formal statement

The model is defined by its spec (`specifications/08-hedging/cross-asset-hedge.md`). This report claims only what the files below show: each listed golden case states inputs, an expected status and, for value-checked cases, expected outputs within the case's tolerance class (`conformance/tolerances/policy.yaml`), and the neutral runner sends every case to all four builds. Whether the four builds pass them at a given commit is recorded by the conformance workflow, not here.

Inputs (read from the inventory entry): spot, dividend yield, flat volatility, a linear-in-zero discount curve; book and hedge instruments; factor weights.
