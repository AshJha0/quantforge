## Open questions for the reviewer

- No library builds this curve. Round 2 (2026-11-18) reads the cumulative funding, spread and fee with QuantLib `LinearInterpolation` and the repo discount factors with `InterestRate(Simple)`; every output is arithmetic on those (`oracle/python/outside_j.py` wave 4, class library-primitive, the class numpy interp earned for scenario replay). All 13 cases agree. It is a check of the interpolation rule and the arithmetic, not an independent model.
- The time inputs are year fractions, not dates, so QuantLib's date-based dividend engine could not price `eq.forward.term_financed` directly without rounding the times.
