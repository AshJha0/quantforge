Classes: `ok` is value-checked (numbers within a stated tolerance); `error` checks the error code only; `same_as` checks that a build answers two related inputs the same way (invariance); `any` is the base of such a pair and passes on any finite answer. A build that answers every case with an error code would pass the error cases and none of the value-checked ones, which is why the value-checked count leads.
