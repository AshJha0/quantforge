# QuantForge question bank

A learning question bank and knowledge check: 371 questions with full answers, in twelve sets that follow the project's topics. It is for two readers. A newcomer can work through the foundation questions in order; a practitioner can jump to a set and test themselves against QuantForge's own conventions and rulings.

How to use it: read the question, answer it on paper, then read the answer. Each answer starts with the plain idea, then gives the formal rule as the spec states it, then (for quantitative topics) a worked example with numbers, and ends with the pitfall that matters on a desk or in validation. Each question names its source spec or tutorial and an evidence class:

- `computed`: the number was produced by running `quantforge_core`; a few are scratch formulas, and the answer says so.
- `spec`: stated in a specification or ruling. `golden`: a named conformance golden case.
- `literature`: a paper or book in the spec's sources. `design`: a project decision recorded in a ruling or ARCHITECTURE.

Every worked-example number is rechecked by a script in `docs/question-bank/verify/` (one per set, `vNN_*.py`), which recomputes it and fails if the printed figure in the page differs. Run them from `python/` with `PYTHONPATH=.`. This page is generated by `verify/build_index.py`; do not edit it by hand.

Levels: **foundation** (the idea and the convention), **practitioner** (using the library correctly and reading its outputs), **advanced** (edge cases, rulings, validation judgement).
