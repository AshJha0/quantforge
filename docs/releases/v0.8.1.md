# v0.8.1 release notes (draft): R6 evidence repair

Draft, last updated 2026-11-12 by the R6 docs lane on branch `r6-docs`, after merging `r6` at `618156d` (all waves READY) and `r6-evidence` at `b9b2b3c`. Not tagged. A cell marked **PENDING `lane`** is filled by that lane before the tag. Nothing here is called fixed without a path to its evidence (plan 14.10 rule 2), and where an acceptance test was not met as worded, this file says so.

## What this release is

An independent review on 2026-11-12 found the evidence layer of v0.8.0 overstated: half the headline golden cases check no number, outside-check shares were counted generously, the mutation gate mutated nothing, and research holdout data had been downloaded and published by the recorder. It also found real model errors (the curve Jacobian, discrete barriers, expected shortfall, the FRTB total). v0.8.1 repairs both before stage J.

Plain idea: a release's numbers are only as good as the checks behind them. This one changes how the numbers are counted, and fixes the models where the review found real errors.
