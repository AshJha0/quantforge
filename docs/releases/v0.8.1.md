# v0.8.1 release notes (draft): R6 evidence repair

Draft, written 2026-11-12 by the R6 docs lane on branch `r6-docs`. Not tagged. A cell marked **PENDING `lane`** is filled by that lane's hand-over before the tag; nothing in this file is called fixed without a path to its evidence (plan 14.10 rule 2). Branch names in the evidence column refer to the R6 lanes, folded into one pull request by the coordinator.

## What this release is

An independent review on 2026-11-12 found the evidence layer of v0.8.0 overstated: half the headline golden cases check no number, outside-check shares were counted generously, the mutation gate mutated nothing, and research holdout data had been downloaded and published by the recorder. v0.8.1 repairs that before stage J. It adds no new pricing.

Plain idea: a release's numbers are only as good as the checks behind them. This one changes how the numbers are counted, and fixes the models where the review found real errors.
