## Changed

- **Behaviour change of a released operation: `risk.backtest.traffic_light` (ruling KR-253, audit KA-A16; audit KF-20).** The operation shipped in v0.10.0. It now takes the non-exception probability `q = c` exactly as given: `x = 0` is `c^n` by double-double binary powering, otherwise the KR-237 binomial sums. Effects (measured on the goldens, `datasets/golden/stage_k/tlk_k.json`): the cumulative probability moves at about the 1e-10 relative level for large n (the old lgamma form drifted past 1e-10 at n = 100,000), and a zone can change on an edge: n = 1, x = 0, c = 0.95 is now YELLOW (exactly 0.95, on the green/yellow edge). Spec `specifications/06-risk/var-es-and-backtests.md` 1.1.0. No existing golden changed; 10 goldens were added (tlk_k-0012 to tlk_k-0021).
- E1 gate refined by ruling KR-112 (owner decision 2026-11-19): an exempt Integer-only operation may carry a Real input only in goldens expecting `E_SCHEMA`; `risk.frtb.backtest.zone` added to the exemption list after planted-fault tests (a) to (d) failed as required (`program/STAGE_K_E1_ZONE_DECISION.md`).
- CLI contract 1.17.0: the stage K wave 1 and wave 1b operations and the K-8 `method` input (`specifications/cli-contract.md`).
- **Stage G margin weights replaced; `xva.simm.ir_delta` renamed `xva.sbim.ir_delta`** (rulings KR-150 to KR-155, `specifications/stage-k-rulings-margin.md`; full list in `program/STAGE_K_MARGIN_REPLACEMENT.md`).
