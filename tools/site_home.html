QuantForge

Quantitative analytics and trading infrastructure, written four times: in Java, C++, Python and Rust. Each language is built separately from the same specification, with no shared code. Expected results come from an independent oracle of hand cases, QuantLib and Strata. Trading is simulated only, and nothing here has been used on a live book.

Quick start

git clone https://github.com/AshJha0/quantforge.git
cd quantforge/rust
cargo build --release
cd ..
python conformance/runner/runner.py --impl rust

Agreement between languages does not prove correctness, and results on synthetic data test the method, not the market. See the README for the full status and known issues.
