QuantForge

Quantitative analytics and trading infrastructure, written four times: in Java, C++, Python and Rust. Each language is built separately from the same specification, with no shared code. Expected results come from an independent oracle of hand cases, QuantLib and Strata. Trading is simulated only, and nothing here has been used on a live book.

Status

Version {{version}} ({{release}}; released {{released}}). Released stages {{implemented_stages}}, and the stage built since (see above), are at Implemented, not Validated. Validation is self-assessment until a human review at the end of the project. Most curve inputs are labelled synthetic, because free quote history does not exist for them.

Honest ceiling. On free public data, QuantForge can show correct pricing and risk, curve quality against published curves, and signals on fitted curves with honest statistics. It cannot show tradable profitability. That needs instrument-level prices, bid and ask, financing and execution data, which cost money. This is a deliberate limit of a zero-spend project.

git clone https://github.com/AshJha0/quantforge.git
cd quantforge/rust
cargo build --release
cd ..
python conformance/runner/runner.py --impl rust

Agreement between languages does not prove correctness, and results on synthetic data test the method, not the market. See the README for the full status and known issues.
