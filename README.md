# curve-daily

Rows written by .github/workflows/curve-daily.yml. Append-only. Label: "fitted to public US Treasury par yields with a library Nelson-Siegel fit; not an official curve". No source file is stored here. A row holds the fitted parameters and the fit error at each of thirteen tenors, from which the thirteen US Treasury par yields used can be worked back; a consistency row holds the differences from the Federal Reserve staff yield curve, from which the Fed values compared can be worked back. Sources, cited as they ask: US Department of the Treasury, Daily Treasury Par Yield Curve Rates. Board of Governors of the Federal Reserve System, Gurkaynak, Sack and Wright (2007), "The U.S. Treasury Yield Curve: 1961 to the Present", FEDS 2006-28 data. Neither source has reviewed or endorsed these rows. See specifications/12-platform/daily-curve-run.md on main (ruling KR-209).
