# paper-ledger

Rows written by .github/workflows/paper-ledger.yml. Append-only. Label: "paper marks on a fitted curve; not tradable". Simulated fills; no performance claim. Each DAY row repeats five US Treasury par yields (3 month, 2, 5, 10 and 30 year) that branch forward-log already publishes. Source: US Department of the Treasury.
